# Income-Statement

## Overview
This Python project helps small business owners calculate their **income, expenses, tax, and net income** for a given year.  
It produces a clear, formatted **Income Statement** that resembles professional accounting reports.

---

## Features
- Collects income, expense,tax data from the user.
- Calculates **total income, total expenses, net income,total tax,net income after tax reduction**.
- Displays results in a structured, professional format.
- Modular design with separate files:
  - `data_collect.py` → Handles input.
  - `income_statement.py` → Handles calculations and output.
  - `main.py` → Runs the program.
